# Angela Closing Prayer

A lighthearted family event page for **The Closing Prayer of Angela Johnson Stanfield** on Saturday, July 25, 2026.

## Publish with GitHub Pages

1. Upload every file in this folder to the root of the `Angela-Closing-Prayer` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. The site should appear at:

   `https://williamsjared79.github.io/Angela-Closing-Prayer/`

The QR code included in this package points to that address.
